# Wednesday 25 November 2026 — The World in One Day

A one-page newspaper front page summing up Wednesday 25 November 2026 in a single image: 50 verified stories across 10 regions. The title names the day's three headline stories — US tariffs proposed on 14 economies, Pakistan's first astronaut boarding Tiangong, and the KOSPI -6.2% Asian chip rout. Below it, 21 illustrated scenes cover the biggest stories, a dense list carries the remaining 29, a UTC timeline strip marks the Shenzhou-24 launch (00:18 GMT) and Tiangong docking (03:56 GMT), and a six-story ticker runs along the bottom.

`main.py` draws the whole image with PIL (standard library plus Pillow) and writes `entry.png` (1024x1024, under 1 MiB). Run it with `python3 main.py`.
